## Working Method for Every Question

1. **Read & Work Out**: Read the input and output format, then work the sample by hand.
2. **Design**: Sketch the class or interface hierarchy: identify abstract elements, and place fields/methods correctly.
3. **Implement**: Write the classes, then `main()` using a base-type reference (**Runtime Polymorphism**).
4. **Format Output**: Format every double with `String.format("%.2f", value)`.
5. **Verify**: Pass the sample, then test extra test cases and boundary / edge constraints.
